# IE Pro 400 GlobalStandard — 有线联网示例

[English](../en/04-wired-connectivity.md) | 中文

**文档版本**：V1.0　**日期**：2026-07-22

## 1. 网口连接

1. 设备提供 **2 路以太网口**（WAN + LAN），均为 10/100 M 自适应 RJ45。
2. 使用标准网线（建议 Cat5e 及以上）连接：
   - **LAN 口**：连接同一局域网内的 PC/交换机，用于本地管理或采集设备联网。
   - **WAN 口**：连接上级路由器/交换机，用于设备出网。
3. 连接后检查网口指示灯：链路建立时常亮或闪烁；不亮表示未连接或线缆故障。

## 2. IP 配置

### 2.1 出厂默认静态 IP

设备出厂时 WAN 与 LAN 口已配置为静态 IP，无需 DHCP 即可直连访问：

| 网口 | 默认 IP | 子网掩码 |
|---|---|---|
| WAN | `192.168.100.126` | `255.255.255.0` |
| LAN | `192.168.101.204` | `255.255.255.0` |

通过 LAN 口 SSH 管理时，将 PC 设置为同网段（如 `192.168.101.100/24`），然后：

```bash
ssh root@192.168.101.204
```

SSH 账号为 `root`，初始密码为一机一密（由产品唯一码生成），详见[《快速上手指南》](02-quickstart.md) §5.2。

登录后查看当前网口配置：

```bash
ip addr show
```

### 2.2 修改 IP 配置

通过 SSH 登录设备后，可使用标准 Linux 命令临时或永久修改 IP：

```bash
# 查看网卡列表
ip addr show

# 临时修改 LAN 口 IP（重启后失效，仅用于调试）
ip addr flush dev eth1
ip addr add 192.168.101.100/24 dev eth1
ip link set eth1 up
```

永久生效需修改系统网络配置文件（路径以实际固件为准，常见为 `/etc/network/interfaces` 或 `/etc/config/network`）。

### 2.3 自定义静态 IP 参数示例

| 字段 | 示例 |
|---|---|
| IP 地址 | 192.168.101.100 |
| 子网掩码 | 255.255.255.0 |
| 网关 | 192.168.101.1 |
| DNS | 8.8.8.8 / 114.114.114.114 |

## 3. Ping 测试

### 3.1 测试局域网连通性

```bash
# 从 PC ping 设备 LAN 口（出厂默认）
ping -c 4 192.168.101.204
```

### 3.2 测试外网连通性

```bash
ping -c 4 8.8.8.8
```

### 3.3 测试域名解析

```bash
ping -c 4 www.example.com
```

正常结果应无丢包（0% packet loss）。若外网 ping 通但域名 ping 不通，通常为 DNS 配置问题，请检查 §2.2 中的 DNS 设置。

## 4. 常见连接场景

| 场景 | 建议 |
|---|---|
| 设备接入企业内网 | 建议使用静态 IP + 内网 DNS，避免与现有网段冲突 |
| 设备直连 PC 调试 | PC 设置为 `192.168.101.x`，SSH 登录 `192.168.101.204` |
| 有线 + 4G 双链路 | 有线优先出网，4G 作为备份；具体路由策略由客户自行配置 |

## 5. 串口测试（可选）

设备串口节点如下，可用于连接现场 Modbus 等设备：

| 接口 | 设备节点 |
|---|---|
| RS485-1 | `/dev/ttymxc1` |
| RS485-2 | `/dev/ttymxc2` |
| RS232-1 | `/dev/ttymxc5` |

测试 RS485-1（9600 波特率）：

```bash
microcom -s 9600 /dev/ttymxc1
```
