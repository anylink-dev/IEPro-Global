# IE Pro 400 Global Standard — 常见问题 FAQ

[English](../en/07-faq.md) | 中文

**文档版本**：V1.0　**日期**：2026-07-22

## 1. SIM 卡不识别

**现象**：`AT+CPIN?` 无返回或返回 ERROR。

排查步骤：

1. **断电**后重新拔插 SIM 卡，确认插入方向正确（金属触点朝向卡槽内侧弹片）。
2. 确认已按[《4G 联网示例》](03-4g-connectivity.md) §2 开启 4G 模组电源（GPIO 69 置 1）。
3. 检查 SIM 卡在手机等其他设备中是否可正常识别，排除卡本身损坏。
4. 执行 `AT+CPIN?`，观察返回：
   - `+CPIN: READY`：卡已识别，问题可能在 APN/网络侧，见第 2 节。
   - `+CPIN: SIM PIN`：卡被 PIN 锁定，需输入 PIN 码解锁。
   - 无返回/ERROR：可能是卡槽接触不良或模组故障，联系技术支持。
5. 检查卡槽弹片是否变形、卡针操作是否到位。
6. 上电后等待至少 60 秒再检查，模组初始化需要时间。

## 2. APN 错误

**现象**：SIM 卡已识别，但无法建立数据连接。

排查步骤：

1. 确认已按[《4G 联网示例》](03-4g-connectivity.md) §2 开启 4G 模组电源（GPIO 69 置 1），且 `/dev/ttyUSB2` 已出现。
2. 确认 APN、用户名、密码是否准确（区分大小写）。常用示例见[《4G 联网示例》](03-4g-connectivity.md) §3.1。
3. 物联网卡通常需要专用 APN，与普通消费卡不同，请向运营商确认。
4. 执行 `AT+CEREG?`（LTE）或 `AT+CGREG?`（非 LTE）确认网络已注册（返回 `0,1` 或 `0,5`）。
5. 确认 SIM 卡套餐已开通数据业务、未欠费停机。
6. 尝试重新拨号：`AT$QCRMCALL=0,1` 后再次 `AT$QCRMCALL=1,1`。

## 3. 无法联网（4G/有线均适用）

**现象**：设备已识别网络/网线已连接，但 ping 不通外网。

排查步骤：

1. 先排查本地链路：
   - 有线：确认网口指示灯正常，检查网线/交换机端口；执行 `ip addr show` 确认已获取 IP。
   - 4G：确认 GPIO 69 已上电且 `/dev/ttyUSB2` 存在（见[《4G 联网示例》](03-4g-connectivity.md) §2）；执行 `AT+CSQ` 确认信号强度，`AT+CEREG?` 确认注册状态。
2. 分层排查：
   ```
   ping <网关IP>        # 排查本地链路
   ping 8.8.8.8          # 排查出网（IP 直连）
   ping www.example.com  # 排查 DNS 解析
   ```
3. 若网关可达但公网不通，检查上级路由/防火墙是否放行、4G 卡是否有公网出口限制。
4. 若仅域名无法解析，检查 DNS 配置（见[《有线联网示例》](04-wired-connectivity.md) §2.2）。

## 4. 无法 SSH 登录设备

**现象**：`ssh root@192.168.101.204` 连接超时或拒绝。

排查步骤：

1. 确认 PC 网卡 IP 与设备 LAN 口同网段（出厂默认 LAN 为 `192.168.101.204`，PC 应设为 `192.168.101.x`）。
2. 先 `ping 192.168.101.204` 确认链路连通。
3. 确认设备已完成启动（约 60～90 秒）。
4. 确认使用正确密码：SSH 账号为 `root`，初始密码为一机一密，需凭产品唯一码向厂家索取（见第 9 节）。
5. 检查 PC 防火墙/安全软件是否拦截 SSH（端口 22）。
6. 尝试通过串口 Console 登录排查（115200 波特率，见[《快速上手指南》](02-quickstart.md) §5.3）。
7. 若已用 `passwd` 修改过密码但遗忘，凭产品唯一码联系厂家重置（见第 6、9 节）。

## 5. 接口接线问题

**现象**：串口/CAN/DI-DO 无数据或工作异常。

| 接口 | 常见原因 | 排查建议 |
|---|---|---|
| RS232/RS485 | 波特率/校验位/停止位不一致 | 核对两端串口参数；确认设备节点路径（`ttymxc1`/`ttymxc2`/`ttymxc5`） |
| RS485 | 极性接反 | 检查 A/B 线是否接反，长距离总线需接终端电阻 |
| CAN | 终端电阻未配置、波特率不一致、接口未启动 | 启动 `can0`；与总线波特率一致（常用 250000 bps）；总线两端各接 120 Ω 终端电阻 |
| DI（X1） | 接线方式错误 | 无源输入（干接点），需与 GND 短接触发（GPIO 117） |
| DO（Y1） | 负载超出额定能力 | 无源输出（干接点），核对规格书 §3.4；必要时加装继电器 |

## 6. Reset 按键与恢复出厂设置

### Reset 按键（GPIO 119）

设备提供 Reset 物理按键，可通过 sysfs GPIO 读取状态：**按压=1，松开=0**。Demo 中可在 GPIO 菜单「监控 DI、DIP 与 Reset 按键」查看实时状态（见 [`demo/README.zh-CN.md`](../../demo/README.zh-CN.md)）。

**出厂固件不提供**长按恢复出厂设置等按键业务功能；若需将按键用于自定义逻辑（如复位、恢复配置），请在应用层自行开发。

### 恢复出厂设置

**适用场景**：忘记密码、配置错误无法恢复。

出厂固件**不支持**通过 Reset 按键恢复出厂。请凭设备**产品唯一码**联系厂家或经销商协助恢复，恢复后典型默认配置包括：

- WAN IP：`192.168.100.126`
- LAN IP：`192.168.101.204`
- SSH 密码：恢复为基于产品唯一码的出厂初始密码

注意：恢复出厂设置将清除所有自定义配置，请提前备份。

## 7. CAN 接口无数据

**现象**：`candump can0` 无输出。

排查步骤：

1. 确认接口已启动：`ip link show can0` 应显示 `UP`（CAN 模块出厂已安装）。
2. 确认波特率与总线上其他节点一致（常用 250000 或 500000）。
3. 使用回环测试验证驱动：`ip link set can0 type can loopback on`（见[《Demo 开发示例》](05-demo-guide.md) §3.2 或 [`demo/README.zh-CN.md`](../../demo/README.zh-CN.md)）。

## 8. 交叉编译工具链无法下载

**现象**：访问 Linaro 官方 `.tar.xz` 直链时跳转到联系页，或 `wget`/`curl` 下载失败。

排查与解决：

1. 使用仓库脚本（自动尝试镜像）：
   ```bash
   sh scripts/setup_toolchain.sh
   . scripts/env.toolchain.sh
   ```
2. 手动从镜像下载，详见 [`toolchain/README.zh-CN.md`](../../toolchain/README.zh-CN.md)（[English](../../toolchain/README.md)）。
3. 完整安装步骤见[《交叉编译工具说明》](06-cross-compile-toolchain.md)「快速上手」章节（[English](../en/06-cross-compile-toolchain.md)）。

## 9. 如何获取 SSH 初始密码

每台设备出厂时部署了**产品唯一码**（印在铭牌或外包装标签上），SSH 初始密码由厂家根据唯一码生成，与设备一一绑定。

1. 在设备铭牌或外包装上找到产品唯一码。
2. 向厂家或经销商提供唯一码，获取对应的 SSH 初始密码。
3. 使用 `ssh root@192.168.101.204` 登录（PC 需与 LAN 口同网段）。
4. 登录成功后，使用 `passwd` 命令自行修改密码。

> 若已用 `passwd` 修改过密码后遗忘，请凭产品唯一码联系厂家协助恢复出厂初始密码（见第 6、9 节）；Reset 按键无法触发恢复出厂。

## 10. 硬件看门狗

**现象**：`/dev/watchdog` 打开失败，或启用后设备意外重启。

排查与说明：

1. 需要 **root** 权限访问 `/dev/watchdog`。
2. 看门狗启用后须由进程持续喂狗；Demo 使用 `iepro_demo watchdog start`（详见 [`demo/README.zh-CN.md`](../../demo/README.zh-CN.md) 与[《Demo 开发示例》](05-demo-guide.md) §3.8）。
3. 停止喂狗且未写入 magic close `V` 时，超时后系统将自动复位——属正常保护行为。
4. 跨终端停止：`iepro_demo watchdog stop`（向 PID 文件中的进程发 `SIGINT`）。
5. 通过看门狗触发重启：`iepro_demo watchdog reboot`（发 `SIGUSR1`）。
